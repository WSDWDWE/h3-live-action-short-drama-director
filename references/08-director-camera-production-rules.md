# 导演、表演、声音与连续性

本文件规定如何拍；容量唯一标准在 `02-timing-and-validation.md`，交付契约在 `01-format-and-delivery.md`。用户本次明确要求优先。

## 输出采用精简执行写法

内部可以充分分析人物目标、情绪层次、视点和节奏，最终视频提示词只保留执行所需的信息。对白镜头通常说清“景别/必要站位 → 谁对谁说 → 主要表情与语气 → 原对白”即可；原稿关键动作、实际运镜、画外/电话声源和必要接点另行简写。

不把人物心理推演、观众应如何理解、为何这样切镜、这次反应怎样完成情绪弧等解释写入正文。不把一种情绪展开成眼睛、眉毛、下巴、手指、呼吸的连续指令；普通交流不额外编排手脚动作或衣料声。这里的精简是减少无关指令与重复，不是删对白、删关键行动或强行限制字数。

## 内部：从戏剧行动到镜头

为每个15秒组先写一句内部意图：谁想得到什么，受到什么阻挡，结尾关系或信息改变了什么。动笔设计画面前，先区分说话人、被讲述者和在场听者；明确关键特征/经历/证据属于谁，讲述发生在当前还是过去。对白提到身体特征或物件，不等于该特征/物件就在说话者或听者身上，也不自动授权现场指认、触摸、拿出或展示。

为每镜先定叙事任务，再选表现手段：原稿行动保留；使既有行动完整可读的衔接补齐；额外表现性动作在内部确认触发和人物动机。只因对白提到一个词、担心画面静止或想凑变化次数而想到的动作，不进入镜头计划。说话方式、信息揭示、视线/关系构图、必要动作和运镜可以择其所需，不要求每镜全部具备。

以下问题供内部设计，不逐项展开到生成正文：

1. 观众当前跟谁看，应该先知道什么、暂时不知道什么？
2. 谁掌握空间、话语或证据，谁在防御、反击、接近或退让？
3. 开始构图的方向、景别、主体位置与必要前后景是什么？
4. 固定机位能否清楚呈现任务？需要移动时，什么信息、动作或发现触发推进、拉开、横移、跟拍或重新构图，最终停在哪里？台词重音可以成为切点或运镜触发，不必同时变成演员的肢体动作。
5. 哪项新信息、动作结果、关键反应或视点变化触发切镜？
6. 台词重音、音量、呼吸、动作声和音乐如何配合；下一镜怎样接？

正文只写选择后的可见、可听安排。例如写“中近景，甲看着乙，生气地质问”已经明确的，就不再解释愤怒如何转化为控制权。信息通过对白逐层揭示时，不另加对应名词的手势；只写 cinematic/emotional 而不说清谁对谁说和什么语气仍然不够。

## 让动作与构图共同成立

- 必要的触碰、指认、抢夺或交接，简短写清谁作用于谁/什么，以及结果。只有左右手、目标归属或交接路线影响结果/连续性时才具体展开；不要给普通对白也补一套手脚位置。对自己与对他人的动作有混淆风险时直接用人物标识。
- 依据动作所需的可见范围选景别。看清甲的表情和乙的手部交互可用明确双人/关系构图；干净特写只承担该构图能看到的任务。若要切换目标，安排实际切镜或重构图，不把两个互不兼容的画面要求塞进同镜。
- 用可拍到的正向状态表达含义。若某项新增动作必须靠“并不表示她有这个特征”“只是象征”等抽象解释才不误导，回到叙事任务重新选表演，不能只追加否定句。原稿必要动作不能因此被删掉，应改清构图和动作关系。
- 镜头计划先确定可见人物、动作归属和声源，出镜清单、参考绑定与正文随后从这份计划生成；仅被对白提及的人不自动入画，画外声也不要求把说话者留在画框边缘。

## 内部选表演：强度由场面决定

下表帮助选择表演，不是每镜需要填满的输出项目。最终通常保留最主要的表情与语气，明确变化时再写变化。

| 场面 | 可执行的表演与摄影任务 |
|---|---|
| 争吵、羞辱 | 写出攻击目标、被刺中的词、反击时机。可以提高音量、断句、抢接和逼近，但动作必须有剧情动机；不默认添加暴力。用距离、遮挡、构图与被打断的动作体现控制权。 |
| 报急、求救 | 语句由呼吸串起，动作有目标与阻挡；把奔跑/拍门/刹停的声响接进切点，不让人物做完所有动作才开口。 |
| 核验、揭穿 | 信息一层层确认；先看到什么、何时相信、证据改变谁的行为必须可见。转折时可定住，让表演接管，不用全程摇晃。 |
| 噩耗、重逢 | 呈现消息怎样改变人物的认知、说话和原本意图；保留原稿冲上前、退让等行动。情境支持时才选择欲上前又停、确认对方或扶住物件，不把一套受惊动作套给每个人。避免统一平静，也避免堆动作。 |
| 温情、认错 | 表现防御如何松动、话如何变得真诚、关系如何靠近；放下物件、跨过阻隔、接住对方动作须有已建立的情境。哽咽可以短暂打断句子，后续台词或必要动作接上，避免长时间无内容凝视。 |
| 商品融入剧情 | 人物为什么此刻拿出、使用、分配商品，结果如何支持关系或理解。把操作拍清楚，避免只坐着讲功能。 |

这些是策略，不是每场都要套同一套镜头。允许自然、强烈、有层次的表演；不把“真人感”解释成全片低声与静止。每个镜头围绕一个主要叙事任务安排表演，不强制每切一镜就新增身体动作、情绪转折或十个面部肌肉词。保留必要的爆发、抢接、逼近与行动结果，让强度来自当下冲突。

## 摄影机与人物调度

- 推进：内部确定动机，正文简写从什么景别推到谁；不每句都慢推，不写无必要的厘米数和摄影参数。
- 横移/重构图：用来揭示已建立的人、阻挡或站队关系；终点要能看到关系变化。
- 拉开：让已建立的空间、距离或动作后果进入画面，不凭空造旁观者。
- 跟拍：跟随已有动作或有真实关系意义的调度，不让人物重复进场或来回踱步。
- 静止：让对白的信息推进、表演、必要动作或前后景关系承担镜头；人物姿势不变也可有明确进展，不能用无内容等待占时长。
- 采用运镜时，每镜至多一个主要运动；固定机位同样有效。遵守可读的轴线、视线与空间方向，越轴必须建立新的空间关系。
- 过肩前景明确属于哪个当前必要人物；没有人物关系作用就用干净构图或门框等环境前景。

有明确情境支持时可以补足导演调度，例如认错者从桌子对面坐到对方身旁。正文写这个动作与必要运镜即可，不附“以此象征从对立到靠近”的解释，也不叠加松包带、低下巴等装饰动作。

## 道具与物体镜头

区分“需不需要参考图”和“需不需要拍到”：普通道具无需单独参考，也可以有必要的镜头。

- 物件镜头用来提供信息、动作结果、关系变化或声音切点；如卡片落桌、钱被推回、照片被翻出、菜被夹开。可用短细节镜头，不要求每次都保留整张人脸。
- 商品操作、数量分配、使用结果可在关系镜头与必要细节之间变化；禁止孤立旋转、无因果美拍作为默认，而非一概禁止功能/结果镜头。
- 道具只描述影响辨认、使用或因果的内容及归属，不为普通收据、袋子、银行卡补装饰纹理和无关小字，也不写空泛的“evidence object”。
- 照片写清已知拍摄对象、动作、地点和画面性质；原稿没给的关键证据不自行编造。
- 同一物件不跨切自动换手；交接过程或段间明确状态必须可见。摘下、放回、收起、打开等改变都记账。

## 对白、反应与声音

逐句绑定人物、声源和原文，用简明表情与语气指导表演。必要重音、抢接或喘息按具体句子补充，不把速度、音量、呼吸和断句逐项列成每句必填字段。声线特征每人每组首次说明，后续用稳定 S 标签承接。

- 长台词可跨切继续，优先保留说话者或关系构图；只在被刺中、发现或决定的瞬间短切纯听者。一般约1秒即可，重大变化允许更久但必须持续发展，不整段挂一张静止脸。
- 反应可叠上一句尾音、抢接、动作声；写明哪位角色的哪句话持续到哪一镜，不能只笼统写“dialogue continues”。
- 每位人物保持独立声线；画外电话、旁白、心声不移到可见人物嘴上，也不自动创造听众。
- 只有影响叙事或接点的声音才单独写，如门外撞击、电话铃、落物声接切镜。普通环境声统一简写，不给每镜加衣袖摩擦、吸气、坐垫响；音效不能代替戏剧变化。
- 音乐按场面选择，用简短说明写有无、主要情绪和低于对白的音量；确有必要才安排精细进出。用户明确要求无配乐则遵守。
- 不设固定沉默尾巴。行动/情绪段的3次变化应是剧情、关系或动作结果，眨眼、点头、抬手不能凑数。

## 连续性与参考控制

内部维护完整连续性。最终提示词只写本组必要开镜状态、实际变化与易混淆的关系，不把整份状态记录逐镜重述，也不背诵长篇负面清单。

- 司机与乘客按剧本和用户纠正安排；不能因为女主在车里就让她开车。座位改变需要原因与过渡。
- 换装调用对应造型图，声线和身份不变；必要造型不能只放备用文件夹不用，也不能一组挂同一人的所有造型。
- 单组参考只保留本组真正需要的可见人；关键动作/反应人物不能被“精简参考”误删，背景人物不为凑群像强留。
- 上一组结束已发生的动作不能下一组重演。独立生成组写清必要当前状态；继承尾帧也需要检查构图、服装、姿势与进出方向。

## 设计的停止条件

如果已说清谁在哪里、对谁说、什么表情语气，以及必要动作，就停止追加描述。仅为解释导演判断、重复已明确状态或装饰画面的句子删去；删后会改变事实、动作结果、声源或连续性的说明保留。节奏与情绪在内部验收，不通过把验收理由塞进正文来证明完成。
