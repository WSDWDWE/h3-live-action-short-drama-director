# 表演、摄影机与连续性

容量按 `02`，格式按 `01`。以下要求用于编写分镜，不把规则原句和创作理由复制进提示词单元格。

## 从剧本确定镜头

先核对谁说话、对谁说、说的是谁、谁在现场，再确定本镜要拍的人与行动。人物目标和事件因果用于选择镜头；最终写实际构图、表演和动作，不解释“象征什么”“让观众理解什么”。

保留原稿行动，补齐必要衔接。新增调度须有当场情境依据，不能因为台词出现身体部位、物件或地点就安排触摸、指认、拿取或走动。讲述往事时拍眼前的交流，不在英文画面段复述场外人、物或特征；原稿明确的展示或闪回另行设计实际镜头。

## 每镜写法

写清景别、必要站位、谁朝向谁、表情语气、原对白与必要动作。固定镜头可以有效；不要求每镜增加手势、表情变化、物件特写或运镜。对白与表演正在推进时，不用额外动作填满画面。

- 构图能容纳需要看清的内容。甲的干净特写不能同时展示乙的脸部反应；需要同时看清两人时用关系构图，需要换视点时实际切镜。双人、三人等构图名称须与本镜要求看清的人物数量一致。
- 触碰、交接、争抢写清人物、对象和完成状态。左右手、接触位置仅在影响归属或连续性时明确；容易混淆时重复Subject标识，不靠含糊代词。
- 避免给新增动作追加“并非表示某事”等解释来补救歧义；重新选择清楚的动作。原稿必要动作通过正确构图保留。
- 切镜写明时点和下一镜拍谁、拍什么。需要触发时用明确台词结束、重音或可见动作节点，不写抽象的剧情含义。一个Shot内不暗藏额外切镜、闪回或时间跳跃。

## 表演强度

| 场面 | 表演写法 |
|---|---|
| 争吵、羞辱 | 明确质问对象、重音、音量和抢接时机；保留有依据的逼近、拦阻和反击，不默认加暴力 |
| 报急、求救 | 焦急、急促但可听清；台词可与已有行动并行，不等所有动作做完才开口 |
| 核验、揭穿 | 随证据逐步确认，在关键回答处加强语气或切到相关人物/物件 |
| 噩耗、重逢 | 按原情境表达震惊、难以置信或急切；保留已有冲上前、退让等动作 |
| 温情、认错 | 含泪、诚恳、放缓或哽咽按具体句子安排；不长时间凝视、哭泣占位 |
| 商品操作 | 拍清原稿的取出、使用、分配及可见结果，保留数量和商品事实 |

声线写稳定音色，情绪随当句变化。避免把“克制自然”变成全片低声，也不堆砌面部肌肉词；明确的表情与语气通常足够。

## 运镜与调度

每镜至多一个主要摄影机运动，写清起点、方向和终点；按实际行动、说话轮次或信息出现安排开始时机。

- 推进：从当前构图推近明确人物或证据，停在指定景别；不每句都慢推。
- 横移/重构图：跟随已有调度，或露出已建立的人与物，写清最终构图。
- 拉开：展示既有空间或动作后果，不凭空增加旁观者。
- 跟拍：跟随原稿或有本场依据的行动，不为运镜安排重复入场和来回走动。
- 固定：由对白、表情或必要动作持续推进，不靠无内容等待。

保持视线、轴线和空间方向；过肩前景明确属于哪个已绑定人物。人物已在场不重新入场；摄影机移动不要求人物也移动。

## 道具与物体镜头

普通道具无需单独参考图，也可有必要的物件镜头。描述只保留有意义的外观、位置、持有人、动作与结果。卡片落桌、照片翻出、商品展开均可作为可见切点，不配动作音效。

照片内容依据原稿已知信息；不编造关键证据。交接前后归属一致，物件不能跨切自动换手。原稿必要文字是道具的一部分，不添加屏幕字幕来替代。

## 对白与反应衔接

无背景音乐、环境音、动作音效和字幕，统一设置见 `01`。人物表演与原稿人声承担强度和节奏。

- 同一人物连续发言时，优先切换该人物的景别或包含该人物的关系构图，台词跨切自然连说。不要为了凑足3—4镜，把整句移到不必要的纯听者镜头上。
- 纯听者镜头只在反应确有变化时短用；普通反应通常约1秒，不机械限时，也不能整段挂静止脸。叠原说话人的台词或尾音时，按 `01` 保留完整说话标识并注明画外声源，不能把台词交给画面中的听者。必要行动可以独立完成，不靠音效或长沉默填时间。
- 原稿画外声、电话、旁白、心声保留来源与稳定S编号，是否带Subject按 `01` 的本组定义规则执行；声音出场不等于人物必须入画。
- 不另外设计呼吸、啜泣或呻吟音效。台词的哽咽、换气和语气变化可以保留，但不挤占必要对白时间。

## 连续性

多人同场时，依据原稿或已经确认的画面，确定本场必要的相邻、对面及朝向关系。原稿未规定时，自主安排清楚且能连续拍摄的位置。没有移动或换位动作时，切镜及连续场景的下一组沿用这些关系；原稿有移动时，保留动作并更新到达位置。摄影机变化时，按新机位描述画面左右，不为构图重新安排人物位置。

分组计划记录造型、站坐、持物、座位、光线方向、未完句与动作，用于核对，不复制成提示词里的核对清单。每组 `Current state:` 只写独立生成所需的当前状态。

- 司机和乘客按原稿及用户纠正安排；车内座位与驾驶职责固定，改变时有过渡。
- 换装使用对应造型图，身份和声线不变；不在一组挂同一人的所有造型。
- 上组完成的动作不无故重演；继承尾帧时检查构图、姿势、服装和进出方向。
- 镜头正文、参考绑定和retention出镜记录保持一致；构图变更时同步更新。

画面能清楚执行、对白连贯、情绪达到该场强度后停止追加描述。不设每镜固定描述字数，也不靠动作数量证明电影感。
