# 容量、拆组与验收

## 唯一容量口径

每一组严格15秒，组内3—4个有效镜头。总组数按需求确定，没有10分钟、40组或其他总量上限；也没有必须超过某个总时长的下限。

| 组内主要段落 | 对白字数/15秒 | 同时要求 |
|---|---:|---|
| 争吵、报急、核验 urgent | 55—80 | 强弱变化、抢话/重音有动机，不能用无限加速塞词 |
| 普通对话 ordinary | 45—70 | 留出换人、呼吸和不能与说话并行的动作 |
| 行动、情绪 action | 20—55 | 至少3次明确的信息、关系或动作结果变化 |

统计对白汉字和英数字字符，不计标点、标签、舞台说明；金额、日期、缩写需按实际读法额外复核，数字字符数不是发声时长。不要再叠加旧“每秒至少4—5字”、旧83—105字上限或“强口播所以更快”的豁免。

在保全对白和必要行动的前提下，采用紧凑、自然的分组；相邻内容能在合规容量内完整合并时，不为延长片长拆开。不能把拆碎后的普通对白随意改标为行动/情绪段，或添加重复收拾、点头、凝视来凑15秒。

这些是规划范围，不是填词目标。不为达下限新增台词，不为压上限删台词，不把普通谈话标成争吵来通过校验。混合段落依据真实动作和情绪归类。低于下限先重排相邻组；原文很短且不可合并的特殊任务，保留原文并明确例外，不能用无变化等待填时间或虚报合规。

## 两级时间预算

**先验整组，再验每个说话窗口。** 全组70字合规，不代表把其中50字塞进开头5秒也合规。

1. 为每组确定类型、全部对白、换人次数、必须完成的动作与状态变化。
2. 把15秒分给3—4个镜头，建立实际发声窗口。一个句子可跨镜连续，镜头切了不等于声音停了。
3. 按语气、字音、轮次估算每个窗口；实际配音可测时长。若安排明显需要赶词，调整窗口、跨镜连续或拆组。
4. 反应镜头由上一句持续的对白或尾音、及时接入的下一句，或正在推进的必要动作承接。不得靠无变化等待填时，也不添加呼吸声、环境音或动作音效填充。
5. 换人和自然呼吸留出发声时间；这不要求另写呼吸音效。非并行动作（吞咽、数钱核对、翻到文件页、开门后才看见某人）要有时间；能够与对白同时完成的必要动作可并行。
6. 结尾镜头也分配实际任务，不统一预留2—4秒无对白脸部停留。

例：15秒内134字、11轮对话、交钱数钱，不能靠“快说”通过。按自然语义把工作邀请与还钱分别规划，再核算每组动作。原片09:52只帮助找场次，不能据此选定40组。

## 全篇覆盖

建立原对白清单和原动作清单；把每项映射到组号/镜头。顺序完整覆盖到最后一场后，才计算N和N×15秒。清单、容量计算和检查结论不写入Excel「提示词」单元格；必要的特殊处理写入「填写说明」。

- 逐字核对原句及标点、说话人、顺序、声源和发生方式；原稿电话、画外对白和旁白的归属保留。“电话对话”不能改成两人面对面仍说“你怎么给我打电话”。
- 核对原稿关键行动、必要触发和结果；无音效要求不等于删掉原稿的可见行动或线索。若核心信息确实只能靠非对白声音或字幕传递，与无音效、无字幕要求的冲突按主规则处理，不自行改成新对白或新事件。
- 对原稿明确的站起、冲上前、退让、拿放、换装、转场逐项核对。
- 不把原稿已有情绪行动当“多余动作”删除；也不为镜头丰富新增剧本未授权的闪回或事实。

## 机械验收脚本

本 Skill 自带 `scripts/validate_storyboard.py`。制作完运行：

```bash
python scripts/validate_storyboard.py --xlsx 成品.xlsx --dialogue-json 原对白.json --plan-json 制作记录.json
```

路径相对本Skill根目录，或使用脚本绝对路径。原对白JSON为有序数组 `[{"speaker_id":"S1","text":"原文。"}]`；制作记录JSON为数组 `[{"seq":1,"mode":"ordinary","state_changes":["具体变化一","具体变化二","具体变化三"]}]`。制作记录独立于Excel「提示词」单元格，不复制为H3生成指令。脚本接受只有原文的字符串数组，但此时不验证说话人。

脚本核对九列表头、序号、是/否、路径与图片槽、Subject/Picture映射、六字段、3—4个标签与时间点、对白字符数量、可选的原对白完整性和分组类型。制作完整剧本时两个JSON均要提供，不能只运行最宽松的结构检查。

脚本不能判断镜头是否真正有效、动作是否合理、图片重要性排序、情绪是否成立或实际发声速度。**标签数通过不等于导演验收通过。** 根据下面清单再人工核对；不可把字符串统计称为实际视频验证。

## 最终人工验收

- 核对3—4个镜头的起止时间、画面和承接；每镜提供新的有效信息、表演或必要动作阶段。同一构图的静态延续不冒充新镜头，运镜写清方向与终点。
- 按逐镜发声窗口复核对白容量、换人、自然呼吸和非并行动作时间；跨镜对白明确归属。表情与语气符合该句情绪，不用机械点头、眨眼或额外手势填时间。
- 原对白与关键行动按清单完整覆盖；电话/现场、当前/回忆、站/坐等未改错。文件名不改变剧本中的年代、人物关系或事实。
- 参考图槽位、Picture、Subject与出镜人物一致，声线编号全片稳定；人物按全片重要性排列，商品/场景在后，原图保留4K、不缩小。
- 组间开镜状态、造型、持物、驾驶职责、空间方向、景别和继承标记连续；最后一组完整可拍。
- 提示词没有配乐、环境音、动作音效或字幕的生成指令；声音只保留原稿口语对白及其电话、画外、旁白来源。规定的无音乐、无音效、无字幕声明保留，剧情解读、设计理由、容量计算和检查结论不进入「提示词」单元格。

仅当错误已修复且未决项已清楚披露后交付。报告实际做过的检查；没有实测音频/视频时只报告文本与时间规划检查。
